# 创想集 AUREUM

逛一次作品展，让一份认可抵达多个好想法。

## 项目概述

创想集面向独立开发者、黑客松团队与创作者，把散落的项目、Ideas、工具、资料及其他作品汇集为公开链上目录。读者无需登录即可浏览，连接钱包后可收藏、领取测试 BLITZ，并通过灵感支持篮用一笔原子交易支持多个作品。作品形态不限，支持完全自愿，资金直接抵达作者。

## 为什么做这个产品

许多好点子和个人项目停留在群聊、笔记和个人仓库。创想集围绕“发现多个值得鼓励的作品后，如何方便地支持他们”组织浏览、收藏、支持与凭证展示。这是当前需要验证的产品假设，尚未通过真实用户留存或付费意愿验证。

## 核心功能

- 开放发布：支持项目、Ideas、工具、资料和其他作品，包含摘要、正文和演示/仓库链接。
- 发现创造：分类、关键词搜索、最新发布/最多支持排序、作者筛选。
- 链上收藏：收藏记录绑定钱包，刷新或换设备后仍可从链读取。
- 虚拟币激励：读者领取无实际价值的测试 BLITZ，通过合约直接转给作者。授权、到账与累计支持均可核验。
- 灵感支持篮：选择最多 20 份作品，一笔批量支持直接分发给作者；任一项失败整笔回滚，必要授权仅覆盖本次总额。
- 可核验体验：发布前展示正文大小与 RPC 费用预览，操作后可查看回执并导出本次会话的交易凭证。
- 作者管理：我的发布、累计获得支持、归档与恢复。归档不抹除历史链上数据。
- 黑金界面：适配桌面与手机，公开浏览无需账号登录。

## Monad 与智能合约

CreationHub 合约存储作品、作者、收藏及支持统计；DemoToken 是基于 OpenZeppelin ERC20 的测试币。支持采用 SafeERC20 与重入保护，代币直接抵达作者钱包，失败交易会整体回滚。前端发送交易前估算 Gas 并增加 10% 缓冲。

Monad 按 gas_limit 计费，因此费用预览按 Gas 上限计算。EVM 兼容性便于复用合约与工具；交易内批处理仍是顺序执行，不能据此宣称已获得并行执行收益。共享统计仍可能产生并发竞争，目前没有公共网络性能证据。

没有 Web2 后端数据库。目录通过合约分页读取，检索与筛选处理已加载的数据；正文公开上链，较大的演示、仓库或附件以外部链接引用。作品并不付费加密，用户支持完全自愿。

## 已验证的演示流程

钱包 A 发布一个 Idea；钱包 B 领取测试币、收藏并支持；检查作者余额精确增加。刷新后重连钱包，收藏保持；作者可归档作品。合约测试、双钱包浏览器回归和 390px 手机布局检查已通过，证据位于 qa-hub/。

新增浏览器回归验证两项作品的批量支持、精确到账、支持篮清空与 JSON 凭证导出。本地可复现实验中，三项同作者支持从单笔合计 311,733 Gas 减至批量 211,408 Gas；这是本地 EVM 测量，不代表 Monad 测试网成本或并行性能。完整范围和复现命令见 docs/REVIEWER-GUIDE.md。

## 技术栈

Solidity、OpenZeppelin、React、TypeScript、Vite、ethers、Ganache、Playwright。使用 MONSKILLS 辅助开发与部署准备。实际代码沿用现有 React/Vite 工程，没有声称使用 Next.js 或 Para。
